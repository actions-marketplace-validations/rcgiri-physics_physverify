# Getting help

- **New to physverify?** Start with [Start here](docs/start-here.md): installation and a first check in about ten minutes, no programming experience beyond running a Python script needed.
- **Using an AI coding assistant?** [Using physverify with an AI assistant](docs/agent.md) has a prompt you can paste and the hook and MCP set-up.
- **A check fails and you are not sure why:** read [Troubleshooting](docs/troubleshooting.md) first; most surprises come from the spec, not the solver.
- **A question:** open a [question issue](https://github.com/rcgiri-physics/physverify/issues/new?template=question.md). No question is too basic.
- **A wrong result from physverify:** use the [bug report](https://github.com/rcgiri-physics/physverify/issues/new?template=bug_report.md).

physverify is maintained by one person in their spare time, so an answer may take a few days.
